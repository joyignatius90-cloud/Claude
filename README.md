# Claude

A project set up for working with [Claude Code](https://code.claude.com/docs).

## Claude Code setup

- **`CLAUDE.md`**: project instructions Claude reads at the start of every session. Edit it to describe your project, commands and conventions.
- **`.claude/settings.json`**: shared settings. It pre-approves read-only commands and blocks reading `.env` files.
- **`.claude/settings.local.json`**: your personal settings. Git ignores this file.
